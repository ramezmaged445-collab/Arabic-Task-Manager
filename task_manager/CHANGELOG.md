# سجل التغييرات / Changelog

جميع التغييرات المهمة في هذا المشروع تُوثَّق هنا.
All notable changes to this project are documented here.

الصيغة مبنية على [Keep a Changelog](https://keepachangelog.com/)، والإصدارات تتبع [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-21

### أُضيف / Added
- واجهة عربية وإنجليزية كاملة (تبديل اللغة من الإعدادات).
- إدارة المهام: إضافة، تعديل، حذف، إكمال، تصنيفات، أولويات، وتواريخ استحقاق.
- تذكيرات مع تنبيهات منطوقة عبر SAPI، ونغمة تنبيه مخصّصة (WAV/MP3/WMA/MIDI).
- تشغيل في الخلفية من أيقونة النظام (tray) مع بدء تلقائي مع ويندوز.
- إتاحة كاملة للوحة المفاتيح وقارئ الشاشة NVDA، مع تباين مريح.
- تخزين محلي في SQLite بدون إنترنت، ونسخ احتياطي/استعادة.
- نسختان: ملف واحد محمول (`ArabicTaskManager.exe`) ومثبّت (`ArabicTaskManager-Setup-1.0.0.exe`).
- قائمة مساعدة: دليل المستخدم، اختصارات لوحة المفاتيح، حول، وتواصل (WhatsApp / بريد إلكتروني).

### ملاحظات / Notes
- التطبيق غير موقّع رقميًا؛ قد يظهر تحذير SmartScreen عند أول تشغيل.
- نسخة PyInstaller من ملف واحد: أول تشغيل قد يستغرق بضع ثوانٍ.
